# Website Folder

This folder contains the revised GitHub Pages-ready personal website.

## Structure

- `index.html`: main homepage
- `styles.css`: shared styles
- `site.js`: footer year script
- `assets/`: CV and photos
- `papers/`: short project summary pages

## Publish

1. Create or open your GitHub Pages repository.
2. Copy the contents of this `website/` folder into the repository root.
3. Push to `main`.

The intended live root is the content of this folder, not the workspace root.
